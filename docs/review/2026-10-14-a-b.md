# CPU training and scoring review

Base: main `0cf5476`. Findings are verified against this revision before
fixing them. Checkpoint, CSV numeric columns and token-file formats stay
unchanged. One finding per commit; every implementation commit passes GCC
and Clang `-Wall -Wextra -Werror`, `make test` (including the real CLI),
`make asan` (ASan/UBSan), and `make tsan`.

| Finding | Evidence and change | Validation |
| --- | --- | --- |
| A1 | night.sh previously supplied no seed. It now uses the first digit group in RUN, or 1 if absent; night1 remains identical. Explicit --seed wins, and resume restores saved RNG. CLI help no longer promises a different order without a different seed. Different seeds change sampling order, not guaranteed corpus coverage. | Two weight-identical INIT checkpoints preserve fresh RNG(seed+1), sample different windows, and mock nightly commands pass seeds 1/2. Existing fresh, conversion and resume checks pass. Full GCC/Clang/native/ASan/UBSan/TSan gate passes. |
| A2 / C10 | Reproduced reasoning evaluation before the final save. Final checkpoint now saves first; an interrupted run skips the final reasoning evaluation. | Real CLI checks output ordering, sends SIGINT after a periodic checkpoint, verifies no final reasoning evaluation, and successfully resumes the interrupted save. Full compiler/native/sanitizer gate passes. |
| A3 / C10 | Reproduced one non-finite-gradient attempt at a tiny time limit returning failure with no checkpoint. Only ten consecutive bad attempts now mark divergence; a time limit below that threshold saves normally. | Normal time limit saves one successful update; a bad-attempt time limit saves step zero with unchanged finite weights and no optimizer advancement. Existing ten-bad-attempt protection still passes. Full gate passes. |
| A4 | Periodic I/O failures now report/continue and keep the last successful save. Failed write/sync/rename paths remove owned temporary files. Flush and file fsync precede atomic replacement (Windows uses _commit); no directory-fsync or power-loss guarantee is claimed. Final saves still fail loudly. | /dev/full failure preserves an existing checkpoint byte-for-byte and removes the temporary link; three periodic rename failures still allow all three updates, then a final checked error preserves the destination. Existing checkpoint continuation/protection tests pass; full gate passes. |
| A5 | Validation and reasoning tokenizer vocabularies were checked too late. Both are now checked before model construction/training. | Real CLI rejects each mismatch before any update/save; valid padded vocabularies still pass. Full GCC/Clang/native/ASan/UBSan/TSan gate passes. |
