# CPU correctness and robustness review

This second review branch depends on the tested A/B fixes. Original code
review base: main `0cf5476`; compatible main documentation through `8917058`
is integrated by ordinary merge. Review/finding IDs follow the owner's
uploaded code-review task. No GPU source or GPU test file is changed.

Each implementation commit passes GCC and Clang `-Wall -Wextra -Werror`,
`make test` including the actual CLI, `make asan` (ASan/UBSan), and `make tsan`.
Object caching is outside the repository and keyed by compiler/flags and
compiler-reported input contents: changed inputs rebuild; every executable
is linked and the full suites run at every gate.

The second PR targets main, but its diff includes A/B until that first PR is
integrated. Merge A/B first; then review the remaining C/D changes. Existing
checkpoint, numeric CSV and token-file formats stay unchanged. Night1's
actual checkpoint/logs are on the owner's laptop, so historical checkpoint
and continuation fixtures are tested here without claiming a laptop run.
